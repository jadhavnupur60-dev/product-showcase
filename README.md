# React Product Showcase

## Project Description
A simple and responsive Product Showcase website developed using React.js. It displays multiple product cards with images, names, and descriptions.

## Features
- Multiple product cards
- Reusable ProductCard component
- React Props for passing product information
- useState Hook for toggling descriptions
- Show and Hide Details functionality
- Dynamic rendering using map()
- CSS Modules for component styling
- Responsive product layout

## Technologies Used
- React.js
- JavaScript
- HTML5
- CSS3
- CSS Modules

## How to Run the Project

1. Clone the repository.
2. Open the project folder in VS Code.
3. Install dependencies:

   npm install

4. Start the application:

   npm start

5. Open http://localhost:3000 in your browser.
